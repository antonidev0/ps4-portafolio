# Dachshund 3D (copia integrada)

Copia del juego de [antonidev0/dachshund-3d](https://github.com/antonidev0/dachshund-3d)
(commit `ce5e834`). Se monta en la ruta `/juegos/dachshund-3d` desde
`src/pages/DachshundPage.jsx` y se carga bajo demanda, así que Three.js no
aumenta el peso del menú.

Para actualizarlo, vuelve a copiar `src/components/`, `src/game/` y
`src/styles/dachshund-game.css` del repositorio original a esta carpeta.
No se formatea con Prettier para que la copia siga siendo idéntica al original.
